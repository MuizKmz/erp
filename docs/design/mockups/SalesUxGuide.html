Pattern 4

Status chips mean the same everywhere

DraftSaved, not yet in effect. Can be edited or deleted.
Pending approvalA policy stopped it. Waiting in someone’s Approvals inbox.
ReleasedIn effect and locked. The next step can start.
PartialSome of it moved on (delivered, invoiced); a balance is left.
DoneNothing left to do.
Cancelled · RejectedStopped. Kept for the audit trail.
Pattern 7

Warnings, blocks and checks

Every message states the problem, the numbers behind it, and what to do next.

Warning · work continues. Over credit limit by RM 50,778.00. Quotations are allowed; the sales order will need approval.
Blocked until someone acts. Credit check did not pass: over by RM 2,400.00. Type a reason and request approval.
Checks before release. ✓ Return qty 5 is within 60 invoiced   ✓ Customer is active   ✓ A reason is given

Field errors sit under the field and name the limit, for example “Deliver now cannot be more than the balance (100).”

Pattern 2

List pages

Every list reads top to bottom in the same order, so users learn it once.

1Title and one line saying what the list holds.
2Four filters in one row: customer or number, a dropdown or two, and a date range.
3Status tabs with counts (All · Draft · Released …). The count is the to-do list.
4Add new on the left, then the module’s next-step button; Import, Export and Select columns on the right.
5Table with the document number as a link. Money right-aligned; status as a chip.
6Pager and a one-line summary at the bottom.

Some lists open with a “waiting” table above them, for example orders waiting to be delivered.

Rules

Six rules users can rely on

1A number is given on the first save and is never reused.
2Released documents are locked. Changes go through a revision, a cancel order, a sales return or a debit note.
3A step can never be bigger than the one before: deliver ≤ ordered, invoice ≤ delivered, return ≤ invoiced.
4Items, customers, prices and tax come from Master Data and are read-only in Sales.
5Policies decide what happens on a problem: allow with a warning, require approval, or block.
6Every approval has the requester’s reason and the approver’s comment, and both are logged.

Pattern 6

When another module is not connected

Inventory is not connected yet.

An amber banner says what is waiting. The work is never blocked: Sales saves an event and the other module picks it up when it is plugged in.
