Step by step

Numbers match the boxes above
Step · screenWhat the user does and seesRules the screen enforcesWhat changes after
1
What happened?
S03 · Document flow
Agent opens the order’s Document flow to see what was delivered, invoiced and returned.Delivered goods cannot be cancelled. Undelivered goods cannot be returned.One of three paths.
2
Draft a cancellation for the balance
S13 · Cancel order listS14 · Cancel balance
From Cancel Order or the order’s Transfer menu. Picks the order; sees ordered, delivered, invoiced and balance; enters cancel qty and reason.Only the undelivered balance can be cancelled. Buy-to-order lines linked to a PO warn Purchase first.CO number, Draft.
3
Release the cancellation
S14 · Cancel balance
Manager reviews and clicks Release cancellation.Permission sales.cancel_order.release. Agents can only draft.Released.
4
Order closes as Balance cancelled
—
Nothing to click.Nothing is posted: the cancelled part was never invoiced.SO status Balance cancelled. Event saved for Inventory.
5
Create a return from the invoice
S27 · Sales return listS28 · Sales return
From Sales Return or the invoice. Picks the invoice, sets return qty, reason, return location and credit method, and adds photos.Return qty can never be more than invoiced minus earlier returns.SR number, Draft.
6
Return qty within what was invoiced?
—
The checklist on the right turns green when every rule passes.Customer active, return location exists, reason given.Release is enabled.
7
Receive goods into Damaged or stock
S28 · Sales return
Store confirms the goods came back and where they went.Damaged goods go to the Damaged location; good ones back to stock.Stock-in event saved for Inventory.
8
Credit note queued for Finance and LHDN
—
Nothing to click.The credit note references the original invoice.Invoice balance drops (RM 16,500.00 → 15,125.00 for SR-0001).
9
Create a debit note on the invoice
S25 · Debit note listS26 · Debit note
From Debit Note or the invoice. Picks the invoice and adds the charge; service items come from Master Data.A debit note always points to one released invoice and never moves stock.DN number, Draft.
10
Release the debit note
S26 · Debit note
Clicks Release.A released debit note is locked.The customer owes more on that invoice.
11
Posting and debit-note e-Invoice queued
—
Nothing to click.The debit-note e-Invoice references the original invoice.Balance rises (RM 15,125.00 + 350.00 + tax for DN-0001).
